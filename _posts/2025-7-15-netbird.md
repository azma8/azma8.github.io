# NetBird: Akses ke Lab Lokal 

Kalau punya **lab pribadi** — pasti pernah ngerasain ribetnya akses dari luar jaringan.  
harus punya IP Publik, konfig Router, setup VPN manual.  
**NetBird** jadi solusi yang simple.

---

# NetBird?

**NetBird** adalah platform **WireGuard-based VPN overlay** yang bisa bikin jaringan privat antar device tanpa ribet dan yang paling penting gratis.  
bisa hubungin laptop, VM, home server, atau lab tanpa ribet.  
Nggak perlu punya IP Publik, setting port forwarding di Router, DNS publik contohnya cloudflare tunnel atau ngrok.  
Semuanya otomatis lewat **peer-to-peer encrypted connection** yang penting punya koneksi intenet.

---

# Cara Kerja Singkat

1. Setiap device install agent `netbird`  
2. Device bakal register ke **NetBird Management Service**
3. Setelah itu, NetBird bikin koneksi **WireGuard tunnel** otomatis antar node  
4. Device bisa saling komunikasi lewat IP yang otomatis dikasih pas register 

Dengan kata lain, semua perangkat di jaringan NetBird kayak punya **VPN overlay sendiri**, tapi jauh lebih simpel dan cepat karena pake wireguard.

---

# Kenapa Cocok Buat Lab Pribadi

Buat yang punya **home server atau lab lokal**, NetBird ini cocok karena:

- **Auto Peer Discovery** – nggak perlu buka port atau atur NAT  
- **Simple Setup** – cukup install agent dan login  
- **End-to-End Encryption** – semua koneksi pakai WireGuard  
- **Multi-Platform** – bisa di Linux, Windows, macOS, Cloud, bahkan Raspberry Pi  
- **Routing** – bisa routing ke jaringan lokal dengan setup yang cukup simple

---

# Contoh Kasus: Remote Akses ke Lab Lokal

Misal punya lab di rumah, dan di dalamnya ada VM atau service yang mau diakses.  
Biasanya cuma bisa akses kalau lagi di jaringan lokal.  

Nah, dengan NetBird:

1. Install NetBird di laptop dan lab pribadi
2. Login pakai token (bisa lewat CLI atau dashboard)  
3. Setelah konek,bakal dapet IP private di jaringan NetBird  
4. tinggal SSH, RDP, atau buka web service antar host kayak lokal network biasa  

bukan berarti kalau pake NetBird service atau home server kita bakal bisa diakses di internet, NetBird itu VPN(Virtual Private Network) untuk akses harus connect ke NetBird
